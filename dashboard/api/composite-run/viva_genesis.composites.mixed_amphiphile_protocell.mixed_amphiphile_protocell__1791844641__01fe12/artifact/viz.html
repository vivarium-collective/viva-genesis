protocell-window

Organic boundaries without isolation — the coarse-grained protocell model (Jordan 2019). Colour is the individuality × access product (retains chemistry AND stays permeable). A single fatty acid is viable only in a narrow corner; adding a co-surfactant (mixed amphiphiles) broadens the window to the alkaline, salty vent point (★) — the boundary enhances persistence without cutting the system off from the gradient.
