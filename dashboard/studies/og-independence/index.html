Independence from the Vent: Can a Lineage Escape Its Cradle?

Q How independent of its geological cradle can a vent-born protocell lineage become — what minimum innovation set lets it persist as external support is withdrawn, which supports can it internalize vs which remain hard dependencies, and is any apparent independence causally attributable to a specific innovation against a matched ablation with input fluxes held equal?

Claim

A vent-born protocell lineage reaches GRADED, attributed independence, not an all-or-nothing (and not a free) escape. og-08 withdrew gradient + mineral + feed JOINTLY and found a coordinated innovation set {internal pump, importer, heredity} where any single removal collapses persistence — but joint relaxation cannot attribute which innovation rescues which support, so that general minimal-sufficiency reading is rescoped to a reduced, model-specific hypothesis (supported within its one coarse model). og-08-alt-robust then tests the set ACROSS model structures on a 2³ subset lattice and resolves it driver-specifically: the {pump, importer, heredity} triple is advantageous but NOT a jointly-necessary irreducible unit — only pump+heredity interact positively, the active importer is required by no driver (a net cost under a leaky membrane), and the hard dependency is the geological gradient (the full set rescues its withdrawal in only ~4.2% of structures), while mineral (0.958) and feed (0.75) are freely/borderline survivable needing no specific innovation. og-37's one-at-a-time withdrawal agrees: the gradient is the budget-sensitive hard dependency (pump-internalization flips below pump efficiency ~0.7, grounded in the energy arm's persistence-not-throughput surplus), while mineral and feed need no innovation. Because the feed is LUMPED (H2+CO2+organics) and the innovations are coarse budget abstractions, this is an affordability/attribution profile, not a demonstrated escape — headline verdict qualified. Every matched null and every arm verdict is preserved explicitly.

Background

Question How independent of its geological cradle can a vent-born protocell lineage become — what minimum innovation set lets it persist as external support is withdrawn, which supports can it internalize vs which remain hard dependencies, and is any apparent independence causally attributable to a specific innovation against a matched ablation with input fluxes held equal?
Hypothesis A bounded innovation set (internal energy conversion + resource import + heredity) allows graded persistence as gradient / mineral / feed are withdrawn; the set's sufficiency is model-structure-dependent, and each internalizable support is attributable to a specific innovation by a matched ablation. Where no subset persists, or apparent independence is not causally attributable, that is reported honestly rather than tuned to a pass.

Model & approach

Relax environmental support by ablation sweeps and determine the minimum innovation set for autonomy (og-08, joint); test minimum-sufficiency across model structures against a generic-environment control (og-08-alt-robust); and reuse og-08's validated co-limited off-gradient budget to withdraw each support ONE AT A TIME with matched per-support ablations, attributing each internalizable support to a specific innovation and reporting the honest profile with its lumped-feed and coarse-abstraction limits (og-37).
